## Featured work

### PlacementPrep - campus placement portal

<a href="https://aiplacement-tracker.vercel.app"><img src="https://img.shields.io/badge/Live%20Demo-4318FF?style=for-the-badge&logo=vercel&logoColor=white" alt="Live demo" /></a>
<a href="https://github.com/tanp4577-web/AiplacementTracker"><img src="https://img.shields.io/badge/Source-181717?style=for-the-badge&logo=github&logoColor=white" alt="Source" /></a>
<img src="https://img.shields.io/github/last-commit/tanp4577-web/AiplacementTracker?style=for-the-badge&color=7C5CFF" alt="Last commit" />
<img src="https://img.shields.io/github/languages/top/tanp4577-web/AiplacementTracker?style=for-the-badge" alt="Top language" />

A browser-based preparation portal for VIT students going through campus placements.

- Resume analyzer that returns an ATS match score with matched and missing skills
- Hiring Hub pulling real openings from public job APIs, with save and bookmark, sorting and direct search links - no hardcoded listings
- Aptitude quizzes, coding practice, skill-gap view, company patterns and an interview experiences wall
- Mobile-friendly UI with a glass-style gradient theme and scroll animations

**Stack:** JavaScript, HTML, CSS, Vercel serverless functions, Gemini API, Groq

### Refactor Guard - safe refactoring for humans and AI agents

<a href="https://github.com/tanp4577-web/refactorgaurd_SYNTAXPLUSE"><img src="https://img.shields.io/badge/Source-181717?style=for-the-badge&logo=github&logoColor=white" alt="Source" /></a>
<img src="https://img.shields.io/github/last-commit/tanp4577-web/refactorgaurd_SYNTAXPLUSE?style=for-the-badge&color=22D3EE" alt="Last commit" />
<img src="https://img.shields.io/github/languages/top/tanp4577-web/refactorgaurd_SYNTAXPLUSE?style=for-the-badge" alt="Top language" />
<img src="https://img.shields.io/github/license/tanp4577-web/refactorgaurd_SYNTAXPLUSE?style=for-the-badge&color=FF4D9D" alt="License" />

Built with Team SyntaxPulse for the Samsung PRISM Gen AI Hackathon 3.0 (Agentic Code Intelligence).

- Rename across Python, JavaScript and TypeScript, plus extract-function and move-symbol for Python, all driven by Tree-sitter ASTs
- Maps the blast radius first and warns about dynamic string references that a find-and-replace would silently miss
- Takes a Git snapshot before editing and rolls back automatically if the tests fail, with optional Gemini diagnosis and one bounded retry
- Minimal Patch Guard reviews a patch for hardcoded outputs, weakened tests and scope creep before it is merged
- Exposes 16 MCP tools so AI coding assistants can call the safety checks inside their own edit loop
- The same repo holds [`code-retrieval-agent`](https://github.com/tanp4577-web/refactorgaurd_SYNTAXPLUSE/tree/main/code-retrieval-agent), the official theme submission for natural-language code retrieval

**Stack:** Python, Tree-sitter, NetworkX, FastMCP, Gemini API, Git
